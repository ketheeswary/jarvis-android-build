JARVIS ANDROID - MOBILE CLOUD BUILD INPUT
=========================================
This is native Kotlin/Jetpack Compose Android SOURCE CODE, not an APK.

Option A: Code2Native (paid native source build)
- On your Android phone open https://code2native.com/
- Use Source Build and select native Android / Android ZIP source.
- Upload JARVIS_Android_CloudBuild_Ready.zip (do NOT extract it).
- Select APK (not AAB), then submit the cloud build.
- Download the signed APK if the build succeeds.
- Native source builds currently require the paid Builder/Pro tier.

Option B: AndroidForge (GitHub Actions, no PC)
- https://professional-x.github.io/AndroidForge/
- Requires your own GitHub fork, suitable token and setup of its Docker
  image as described by the AndroidForge project. Do not share your PAT.
- Upload the same ZIP, select debug APK, build, then download artifact.

IMPORTANT:
- An APK generated from this starter is NOT a standalone finished JARVIS:
  the AI chat requires a separately configured and reachable Python server,
  with an OpenAI API key and an app token. The app does not contain an API key.
- Windows PC actions require the Windows agent actually running.
- Home Assistant actions require Home Assistant setup and authorization.
- The JARVIS wake word is foreground-only in this starter.
- Cloud builds were not executed or verified from this environment.
- Do not upload actual .env files, OpenAI API keys or secrets to builder services.
